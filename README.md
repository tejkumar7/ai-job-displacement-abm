# ai-job-displacement-abm
Agent-based simulation of the economic effects of AI displacing software jobs. Code and data for a working paper by Tej Kumar Tiruveedula.

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.23633673.svg)](https://doi.org/10.5281/zenodo.23633673)

Paper: Tiruveedula, T. K. (2026). When the Code Writers Are Automated. Zenodo. https://doi.org/10.5281/zenodo.23633673



## How to run

pip install numpy pandas matplotlib joblib
python3 run_experiments.py
python3 run_sens.py
python3 analyze.py
python3 analyze_sens.py

All model parameters are in the `Params` section of `aiecon_abm.py`.

## Note

Stylised model, not calibrated to a specific country. Results are illustrative. Prepared with AI assistance (Claude, Anthropic).
